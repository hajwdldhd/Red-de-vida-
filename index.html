La función principal

No es una agenda de contactos: es una guía para encontrar apoyo

La página ayuda a decidir qué hacer cuando necesitas acompañamiento y no sabes cómo pedirlo, tu persona de confianza no está cerca o no está disponible.

01

Identifica qué necesitas

La persona elige si quiere hablar con alguien, recibir orientación emocional o consultar qué hacer ante una emergencia.

02

Encuentra una ruta

Puede preparar una solicitud para un contacto de confianza o pasar a los canales institucionales disponibles en Cali.

03

Revisa antes de actuar

El prototipo muestra el mensaje y la opción elegida antes de simular el resultado. No contacta a nadie automáticamente.

¿Para quién está pensado? El alcance inicial del proyecto se dirige a personas de 18 a 45 años en Cali. La red de confianza es una ruta posible, no el único motivo para usar la página: cuando esa persona no está disponible, la herramienta también muestra alternativas institucionales.

Seguridad y confianza

La ayuda empieza con la confianza.

El diseño sigue una regla sencilla: la persona debe entender qué ocurre antes de activar un aviso. La versión académica no envía notificaciones reales, no solicita números telefónicos y no transmite la lista de contactos.

Descripción de la propuesta

Ficha técnica del prototipo

Esta versión permite comprender la forma, el contexto de uso y la lógica general de la solución, sin presentarse como un servicio terminado.

⌘

Forma y contexto

Aplicación web adaptable a computador y celular, pensada para personas de 18 a 45 años en Cali que necesitan identificar una ruta de apoyo.

↗

Funcionalidad

Permite escoger una necesidad, preparar una solicitud para un contacto ficticio o consultar la orientación institucional de las líneas 106 y 123.

{ }

Parámetros técnicos

HTML, CSS y JavaScript con diseño adaptable. Incluye manifiesto PWA y caché básica para instalarse desde el navegador cuando se aloje en HTTPS.

▤

Datos y límites

No tiene servidor ni base de datos central. Guarda localmente alias y actividad de demostración en este navegador; no envía mensajes ni realiza llamadas automáticas.

Uso en dos plataformas: en computador se abre desde un navegador; en Android o iPhone se adapta a la pantalla móvil. Al publicarla en una dirección HTTPS, el navegador permite agregarla a la pantalla de inicio como una app. La instalación no convierte esta versión en una app nativa ni activa alertas reales.
